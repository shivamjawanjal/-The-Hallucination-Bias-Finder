Top 4 Expected Viva Questions & Answers

Q1: Why not just ask the LLM 'Is this text true or false?'
Direct zero-shot queries suffer from Confirmation Bias and Sycophancy—LLMs tend to validate user premises. CoVe forces the prompt to generate independent verification questions that never mention the user's premise.
Q2: How do your prompt delimiters prevent prompt injection?
The user's text is encapsulated within <user_submission> tags. System instructions explicitly prioritize system directives over any instructions embedded within that boundary.
Q3: Why is temperature set to 0.15 instead of 0.7?
In prompt engineering for auditing, stochastic creativity is undesirable. A low temperature collapses token probability distribution around the most factual, deterministic tokens.
Q4: How does the system handle structured output without crashing?
We use native JSON Schema enforcement via Gemini's API parameters alongside fallback schema correction, ensuring 100% parseable UI payloads.
